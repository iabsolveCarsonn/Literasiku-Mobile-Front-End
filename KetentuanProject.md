# 1. Ketentuan Umum

Setiap kelompok wajib mengumpulkan "Log Book" yang berisi dokumentasi tugas-tugas (task) pengembangan aplikasi mobile berbasis back-end.

Ketentuan Task:

1. 3 task per mahasiswa
2. Setiap task harus berisi:
3. Kode program (file atau potongan kode yang relevan).
4. Bukti hasil kerja berupa foto atau video hasil implementasi program.
5. Nama penanggung jawab dari masing-masing task.

Catatan: Nilai antar anggota tim dapat berbeda tergantung pada kualitas dan kompleksitas task yang dikerjakan.

# 2. Daftar Task Wajib

Setiap tim harus mengimplementasikan fitur-fitur berikut dengan fungsi yang realistis sesuai kebutuhan dunia nyata, bukan hanya contoh sederhana dengan menerapkan:

1. Flutter Fundamentals: Penerapan Scaffold.
2. Vibe Coding Fundamentals: Vibe Coding dengan jelas.
Flutter UI Components: Text, Icon, Image, RichText, CircleAvatar, Reusable Widget.
3. Material Design & UI Dasar: Material 3, warna, typography, spacing, hierarchy, components.
4. Flutter Layout Dasar: Alignment, Container, Padding, SizedBox, Center.
5. Flutter Multi-Child Layout: Row, Column, ListView, GridView, Stack, Expanded, Carousel.
6. Responsive & Adaptive UI: Constraint, ukuran layar, orientasi, dan adaptasi layout.

# 3. Format Pengumpulan
1. File disimpan dalam format Excel (.xls).
2. Nama file: Nama_Tim.xls
3. Setiap sheet dalam Excel dapat berisi:
	1. Identitas Anggota Tim
	2. Daftar Task per Anggota
	3. Deskripsi Program dan Bukti Implementasi
